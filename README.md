# ASTREX: Поисково-аналитическая система [Ultra-Lite Edition]

Архитектор: Praxis 
Платформа: Исключительно Linux (система протестирована в различных средах, включая минималистичные оконные менеджеры вроде Openbox на базе BlackArch)
Статус: Public Release / Community Edition (Специальная сборка)

---

## ⬛ ОПИСАНИЕ ПРОЕКТА
ASTREX — это проприетарная высокопроизводительная поисково-аналитическая система. Оригинальная архитектура разрабатывалась для глубокого мониторинга, агрегации колоссальных массивов информации и предиктивной аналитики, требуя значительных серверных мощностей и огромных объемов оперативной памяти. 

Данный репозиторий содержит специально подготовленную Ultra-Lite версию ядра ASTREX. Для обеспечения возможности локального запуска на стандартных пользовательских устройствах был проведен масштабный рефакторинг, система оптимизирована для работы «из коробки» без сложной настройки сред окружения.

---

## ⚠️ АРХИТЕКТУРНЫЕ ОГРАНИЧЕНИЯ И ОТКЛЮЧЕННЫЕ МОДУЛИ
Учитывая ограничения аппаратного обеспечения обычных ПК, в данной версии применены следующие архитектурные усечения:

1. Исключительно Linux: Сборка написана и скомпилирована строго под ядро Linux. Поддержка операционных систем семейства Windows отсутствует на фундаментальном уровне. Запуск через подсистемы (WSL) или виртуальные машины не гарантирует заявленной производительности и стабильности интерфейса.
2. Отключение глобальных баз данных: В целях радикального снижения потребления ресурсов, модули интеграции с внешними и глобальными базами данных полностью деактивированы. Анализ производится локально.
3. Удаление тяжеловесных компонентов: Из текущей сборки полностью вырезан специфический функционал, включая алгоритмы обработки спутниковой телеметрии и системы непрерывного мониторинга кинетических угроз.
4. Урезанный NLP-движок: Модуль обработки естественного языка (Natural Language Processing) интегрирован, но его функционал ограничен базовым семантическим анализом, поиском паттернов и токенизацией. Глубокие нейролингвистические цепи отключены.

---

## ⚙️ ДОСТУПНЫЙ ФУНКЦИОНАЛ
Несмотря на удаление ресурсоемких модулей, ядро ASTREX сохраняет высочайшую эффективность в рамках локальных задач:
* Мультиформатная обработка данных: Система способна на лету индексировать, структурировать и анализировать более 60 форматов данных (включая текстовые массивы, бинарные файлы, дампы трафика, метаданные и системные логи).
* Интегрированный GUI: В релиз включен полноценный графический пользовательский интерфейс для визуализации процессов и комфортного управления системой без обязательного использования командной строки.
* Стабильность: изоляция воркеров (сбой, зависание или переполнение памяти на одном файле не останавливает скан), лимиты времени и памяти на файл, автоматические тесты (`python -m unittest discover -s tests -t .`) и самопроверка (`python selftest.py`).

## 🚀 УСТАНОВКА И ЗАПУСК

Нужны: Linux, Python 3.10+ (проверено на 3.13) с модулем venv, для GUI — Qt 6.

### Шаг 1. Получение файлов

```bash
git clone https://github.com/viktorpolanitsa/ASTREX-Ultra-Lite-Edition.git
cd ASTREX-Ultra-Lite-Edition
```

Или скачайте ZIP (Code → Download ZIP) и распакуйте. При распаковке ZIP права на
исполнение теряются — установщик их восстанавливает (или: `chmod +x install.sh ui/Astrex ui/build.sh`).

### Шаг 2. Установка зависимостей

```bash
bash install.sh                    # интерактивно: режим, GPU, проверка системы
bash install.sh --yes --mode full  # без вопросов
```

Установщик создаёт `venv/` в папке проекта, ставит Python-пакеты по выбранному режиму
(minimal / standard / full / complete), подбирает PyTorch под GPU, проверяет системные
утилиты и запускает самопроверку. Необязательные утилиты (Debian/Ubuntu/Kali):

```bash
sudo apt install python3-venv tesseract-ocr tesseract-ocr-rus unar pst-utils mdbtools ffmpeg postgresql-client nfdump
```

### Шаг 3. Запуск

**GUI:** `./ui/Astrex` (или двойной клик в файловом менеджере). Программа сама находит
бэкенд (`../astrex.py`) и интерпретатор из `venv/` проекта; переопределить можно
переменными `ASTREX_BACKEND` и `ASTREX_PYTHON`.

Готовый бинарник собран с Qt 6.10 для обычного x86-64. Если система сообщает
`version Qt_6.10 not found` или Qt 6 не установлен — соберите GUI из исходников:

```bash
sudo apt install build-essential qt6-base-dev
./ui/build.sh
```

**Командная строка:**

```bash
source venv/bin/activate
python astrex.py scan "Иванов" /path/to/documents      # поиск с извлечением сущностей
python astrex.py index /path/to/archive                # предварительная индексация
python astrex.py search "договор"                      # быстрый поиск по индексу
python astrex.py status                                # состояние системы
python astrex.py --help                                # все команды
```

**Web API:** `python astrex.py web` — сервер на http://127.0.0.1:8080, запросы с заголовком
`Authorization: Bearer <токен>` (токен — в `~/.astrex/.secret_key` или переменной `ASTREX_API_TOKEN`).

Данные (индекс, логи, настройки `config.yaml`) хранятся в `~/.astrex` (переменная `ASTREX_HOME`).
Подробная документация — в [info.md](info.md).
